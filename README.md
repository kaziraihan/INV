
# 🖥️ IT Asset Inventory System

A lightweight, web-based IT Asset Management system designed to efficiently track assets, their assignment history, and employee/customer details. Built with PHP, MySQL, and Bootstrap — perfect for small to medium-sized organizations seeking an open-source solution for managing IT infrastructure.

## 📌 Features

- 🔍 Employee/Customer Management (Add, Update, Delete)
- 📦 Asset Assignment and Return Tracking
- 🗂️ Asset Status Filtering (Assigned, Unused, Archived)
- 🔃 Dynamic Search and Sorting (with Vanilla JS)
- 📑 Download pdf reports
- 🖨️ Printable Reports
- 📈 Responsive UI with Bootstrap 4
- 🔐 Role-based Access Control *(Admin, user, etc.)*


## ⚙️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap 4, JavaScript
- **Backend**: PHP (Vanilla PHP)
- **Database**: MySQL


## 🚀 Getting Started

### Prerequisites

- PHP ≥ 7.2
- MySQL or MariaDB
- Apache or any web server (XAMPP, WAMP, LAMP)

### Installation

1. **Clone the repo:**

https://github.com/kaziraihan/INV.git

Import the database:

Open phpMyAdmin or use CLI.

Import the database.sql file located in the root directory.

Configure the database connection:

Open db_config.php or config/connection.php and update with your MySQL credentials:

$host = "localhost";
$user = "root";
$pass = "";
$dbname = "root_system";


Launch the application:

Run the project from your localhost:
http://localhost/inv/admin/
